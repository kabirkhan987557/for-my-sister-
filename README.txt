Khekasha's Birthday Website
============================

Files:
- index.html: the complete website (styles, animations, countdown, letter, surprise, and synthesized soft piano music are all included).

Preview:
1. Extract the ZIP.
2. Double-click index.html to open it in your browser.
3. Press “Play soft piano” to start the gentle music (browsers require a user click before audio can play).
4. Tap the envelope to reveal the letter and the surprise button to reveal the final message.

Publish free with GitHub Pages:
1. Create a new public GitHub repository, for example `khekasha-birthday`.
2. Upload `index.html` to the repository root.
3. Open Settings -> Pages.
4. Under Build and deployment, select “Deploy from a branch”.
5. Select branch `main` and folder `/ (root)`, then Save.
6. After GitHub publishes it, open the URL shown in Settings -> Pages and send that link to Khekasha.

The countdown automatically targets the next upcoming November 23 based on the visitor's device date/time.
